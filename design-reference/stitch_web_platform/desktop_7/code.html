Присідання зі штангою на спині

Класичний присед з олімпійським грифом (Barbell Back Squat) — фундаментальний рух для сили та маси нижньої частини тіла.

info

Фізіологічне значення та опис

Присідання зі штангою на спині справедливо вважаються «золотим стандартом» важкої атлетики та бодібілдингу. Цей рух запускає потужний системний нейроендокринний відгук організму, стимулюючи вироблення соматотропіну та ендогенного тестостерону. Вправа зміцнює кістковий апарат, тренує зв’язковий комплекс нижніх кінцівок, покращує рухливість гомілкостопів та формує надійний силовий корсет для поперекового відділу хребта.

Вправа є базовим багатосуглобовим рухом закритого кінематичного ланцюга із залученням чотириголових м'язів стегна, сідничних м'язів, задньої поверхні стегна та глибоких м'язів-стабілізаторів корпусу.
